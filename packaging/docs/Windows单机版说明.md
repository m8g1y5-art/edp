# 具身数据平台 · Windows 单机版说明

单机版装在一台 Windows 电脑上使用，适合试用和小批量数据。打开网页不需要登录。

## 安装

两种安装方式，选一种即可：

- **安装程序**：双击 `edp-<版本>-setup.exe`，默认装到 `C:\EDP`。
- **压缩包**：把 `edp-<版本>-windows.zip` 解压到一个纯英文路径，比如 `C:\EDP`。

安装路径不能含中文，否则手部关键点模型会加载失败。

建议使用 NVIDIA 显卡（8 GB 显存以上）。没有显卡也能运行，但物体跟踪会很慢。

## 启动

双击桌面上的“具身数据平台”（或安装目录里的“启动.bat”）。浏览器会自动打开 http://127.0.0.1:8765 。用完关掉黑色窗口就会停止。

## 许可证

第一次使用时，到“设置 → 授权”上传供应商给的许可证文件（`.lic`）。如果许可证需要绑定这台电脑，先把同一页上的“本机指纹”发给供应商。

没有许可证或许可证过期时，可以浏览、校对、导出已有结果，但不能开始新的处理。

## 数据在哪里

所有数据都在安装目录的 `data` 文件夹里，包括数据库、处理结果、预览视频和导出的数据集。原始录制不会被改动。卸载程序时 `data` 文件夹会保留。

## 管理工具

双击“管理工具.bat”可以查看本机指纹、安装许可证、查看数据库版本，或者把数据库恢复到升级前的备份。
