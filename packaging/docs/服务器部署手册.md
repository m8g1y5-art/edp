# 具身数据平台 · 服务器部署手册

本手册给客户的运维人员使用。整套平台跑在客户自己的服务器上，数据不经过我方。

## 1. 硬件与系统要求

| 项目 | 最低 | 建议 |
| --- | --- | --- |
| 操作系统 | Ubuntu 20.04 / 22.04 / 24.04（或其他装了 Docker 的 Linux） | Ubuntu 22.04 |
| 显卡 | NVIDIA，显存 16 GB，计算能力 7.0 以上（V100 起） | 24 GB 以上；多卡会自动并行 |
| 显卡驱动 | 支持 CUDA 12.6（驱动 560 以上） | 最新稳定版 |
| 内存 | 32 GB | 64 GB 以上 |
| 磁盘 | 系统盘 50 GB（镜像约 15 GB）+ 数据盘按数据量 | 处理结果约为原始数据的 1/5 |
| 软件 | Docker 24+、docker compose 插件、nvidia-container-toolkit | |

如果要在内网跑视觉大模型（数据完全不出内网），还需要一张 24 GB 以上的显卡给大模型，或者和处理共用一张 48 GB 以上的卡。

## 2. 安装

把发布包 `edp-<版本>-linux.tar.gz` 和许可证文件（`.lic`）拷到服务器上：

```bash
tar xzf edp-1.0.0-linux.tar.gz
cd edp-1.0.0
sudo ./install.sh /opt/edp /path/to/客户.lic
```

安装脚本会依次检查 Docker 和显卡驱动，导入镜像，在 `/opt/edp` 下建好目录和配置文件，启动服务，最后让你设置管理员的用户名和密码。安装完成后会打印网页地址和本机指纹。

安装目录结构：

| 路径 | 内容 |
| --- | --- |
| `/opt/edp/.env` | 部署配置（端口、目录、是否允许外部大模型接口等） |
| `/opt/edp/data/` | 数据库、处理结果、预览视频、许可证、数据库备份 |
| `/opt/edp/imports/` | 原始录制放这里，网页“导入”时从这里选 |
| `/opt/edp/exports/` | 导出的数据集 |
| `/opt/edp/edpctl` | 运维命令 |

`imports` 和 `exports` 可以在 `.env` 里改成网络盘的挂载点，改完执行 `./edpctl restart`。

## 3. 日常运维

```bash
cd /opt/edp
./edpctl status                     # 服务状态、版本、数据库版本
./edpctl logs worker                # 看处理日志（logs web 看网页服务）
./edpctl restart
./edpctl backup                     # 手动备份数据库
./edpctl manage reset-password admin
./edpctl license 新许可证.lic        # 更换许可证（也可以在网页“设置 → 授权”上传）
```

备份建议：每天备份 `data/app.db`（用 `./edpctl backup` 生成的副本在 `data/backups/`）和 `data/secret.key`（外部接口密钥的加密钥匙）。处理结果（`data/batches/`）可以从原始数据重新生成，按需备份。

## 4. 升级与回退

```bash
tar xzf edp-1.1.0-linux.tar.gz
cd /opt/edp
./edpctl upgrade /path/to/edp-1.1.0
```

升级会先备份数据库，再换镜像、重启。新版本启动时如果需要改数据库结构，会自动执行，并在 `data/backups/` 里留一份升级前的备份。

如果新版本有问题，可以回到旧版本：

```bash
./edpctl rollback 1.0.0
```

它会停掉服务，让你选一个数据库备份（选升级前那份，文件名里带 `-v<旧数据库版本号>`），恢复后用旧镜像启动。

## 5. 账号与权限

| 角色 | 能做什么 |
| --- | --- |
| 管理员 | 所有操作；另外可以改设置（模型、资源、动作词表）、管理账号、上传许可证、删除项目和批次、查看操作日志 |
| 标注员 | 导入、预检、开始处理、浏览校对、导出 |

账号在网页“设置 → 账号”里由管理员添加。所有写操作和登录都记在“设置 → 操作日志”里。

## 6. 大模型与数据安全

语义标注需要视觉大模型，有两种用法：

1. **内网模型（数据不出内网）**：在 `/opt/edp/models/` 放好模型文件，执行 `docker compose --profile vlm up -d` 启动内网模型服务，然后在网页“设置 → 视觉大模型”里把接口地址填成 `http://vlm:8000/v1`。
2. **外部接口（如阿里云百炼）**：速度快、模型强，但抽取的画面会发送到服务商。

如果客户要求数据绝对不出内网，在 `.env` 里设置 `EDP_ALLOW_EXTERNAL=0` 并重启。这样网页上也无法再打开外部接口，平台只会调用内网地址。

## 7. 许可证

许可证过期或无效时，不能开始新的处理；浏览、校对、导出已有结果不受影响。到期前 30 天，网页顶部会提示续期。

需要绑定机器的许可证时，把 `./edpctl manage license fingerprint` 输出的指纹发给供应商。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 网页打不开 | `./edpctl status` 看 web 是否在运行；防火墙放行 `.env` 里的端口 |
| 任务一直排队不动 | “设置 → 运行资源”里看处理进程是否在线；`./edpctl logs worker` 看报错 |
| worker 起不来，日志里提到 nvidia | 安装 nvidia-container-toolkit 后执行 `sudo systemctl restart docker` |
| 显存不够 | 平台会自动减少并发并重试；也可以在“设置 → 运行资源”里把每张卡同时跟踪数改小 |
| 忘记管理员密码 | `./edpctl manage reset-password admin` |
