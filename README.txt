具身数据平台 · 本机试用版

启动：双击 run.bat。第一次会自动建 Python 环境并安装依赖（清华镜像，3-8 分钟），之后几秒启动。
浏览器会自动打开 http://127.0.0.1:8765 ；关掉黑色命令行窗口就停止服务。

流程：导入（填本机文件夹路径，或拖入文件夹）→ 预检（自动分组、输入质量 A/B/C/D、处理计划）
      → 开始处理（实时进度）→ 浏览（视频 + 深度同步播放、手部关键点、分段可改）→ 导出数据集

本地视觉模型：自动连接本机 Ollama（127.0.0.1:11434），自动选第一个视觉模型（如 qwen2.5vl / qwen3-vl）。
              没有 Ollama 也能跑，语义步骤会标“跳过”，装好后在浏览页点“重跑”。

数据：原始数据从不改动。处理结果、预览视频、导出的数据集都在本文件夹的 data\ 下。
